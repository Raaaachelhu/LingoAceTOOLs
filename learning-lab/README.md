# LingoAce 听读拓展与测评

PU Level1-3 各9单元，RH Level4-7 各8单元，自研 Level1-8 各8单元，共123单元。

本次新增96单元的测评、分角色听力、朗读及打印卷；原有主题词、拓展阅读与家庭活动按单元保留整理。自研Level1-3的阅读短文重新编写，适合基础听读。各教材内等级不直接等同。

每单元：主题词和拓展词、4组语言示例、语音提示、阅读、家庭活动、20道客观题（90分）与2项口语（人工评分10分），学生卷与答案卷各一份。阅读小测复用学习页短文，适合学后形成性评估。不是出版社原题或标准化考试。

音频：Kokoro 神经网络合成英语（美式音色），不是出版社或真人录音。词汇与表达、阅读、测评各一条。测评中的新对话用两种音色区分A/B角色；每题两遍并留作答停顿。语速按基础/进阶范围设置，网页也可调速。

音频是可直接下载的MP3，离线保存后播放不依赖语音API。Kokoro模型Apache-2.0，kokoro-onnx运行工具MIT；模型和生成工具不需要上传到网站。

所有练习数据随网页下载；答案辅导页可见，不是保密考试系统。答题只在当前页面内存，刷新会清空。口语由教师/家长按任务、目标语言、可理解度评分，不自动评价发音。

原资料中合并的数字、月份、星期和过去式条目已在新增模块拆分整理；若干多义词采用本单元语境释义。
