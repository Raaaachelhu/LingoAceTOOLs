# 使用说明与覆盖清单

共 3 套教材、20 个 Level、135 个 Unit、2355 条单元词汇记录、1660 个不同源词条。

## 文件使用

1. 解压后打开“全部教材_词卡与故事.html”；可筛选、搜索、暂停动画、朗读和打印。
2. 教材目录 → Level → Unit 内，词卡与故事各自为独立 HTML。每个文件自带样式、插图、数据和脚本，无需联网加载资源。
3. 每个 Level 另有词卡合集与故事合集，适合批量打印。选择浏览器“打印 → 存为 PDF”。
4. CSV 可用 Excel 打开；JSON 便于后续导入工作台；Markdown 保留原版与补充版故事文本。
5. 所有 Unit 在各自页面完整展开。教材、Level 筛选只帮助定位，不需点击切换一张张卡片。

## 提取规则

按源程序的单元词卡规则：跳过 isReview=true 的复习课，按原顺序合并并去重；保留复合词、过去式、数字分组、人名与原始拼写。重复词对应多个课时，均列出来源。词卡句型来自对应课时，未冒充新编逐词例句。
原故事按完整源程序规则复现：一致的 context、哈希、主题、最多 10 词抽样、词性句框与中文标注。原 HTML 本身未保存固定故事正文。
补齐 19 个中文查词缺口；补充故事每 Unit 一篇，共 135 篇，并分别列明已覆盖和未在正文使用的单元词。不会为了塞入全部词汇而破坏故事语义。

## 视觉说明

采用 SVG 矢量实物、身体定位、动作、颜色和空间关系图，以及带文字提示的情境分镜；部分具体词仍使用原有 emoji 构建图标场景。其余使用中英词义关系图，不等同于独立定制插画。不同系统 emoji 外观可能不同。动画包括移动、跳跃、轻摆、雨滴与重点定位提示；可暂停，尊重设备减少动态效果设置。
数字分组不擅自拆成额外词条。多个词义或形态同列的词保留源条目，配图仅作理解提示。抽象词分镜说明概念关系，正文释义才是词义依据。

## 教学延伸

低 Level：指图、中文提问、跟读、摆放、三格复述，家长不必即兴说英语。
高 Level：每个单元有主题任务、证据与推断问题、语言支架、词汇迁移和写作建议。等级是教材内部标识；Power Up、Reach Higher 与自研同编号不代表同一难度。
