# Power Up 听读拓展与测评

覆盖 Level1–3，各 Unit1–9。原创补充练习，按现有第一版单元目录对齐；不是教材原卷，也不是官方考试预测。

每单元 12 张文本词汇卡（前 8 个为主题词，后 4 个为拓展词）、4 组表达、拼读建议、原创故事、家庭任务、20 道客观题及 2 项口语任务。客观题 90 分，口语人工评分 10 分；网页不自动评价发音。

MP3 为本地合成英语朗读（美式音色），不是出版社录音。词汇、故事和测评听力各一条，共 81 条。测评每题读两遍并留停顿。音频、学生卷、答案卷均按单元编号对应。

学生与答案 PDF 可分单元下载；bundles 中含每个 Level 的合集。网页也可以打印当前练习。进入 index.html 使用，访问密码沿用工作台设置。答题只保留在当前页面内存，刷新会清空。

范围依据：已上传的 PU 教材目录与课次资料；Level3 后五单元参照 Cambridge 官方 scope and sequence 的主题及语法范围，所选词汇与全部故事/试题为原创补充，不声称完整重现教材词表。
